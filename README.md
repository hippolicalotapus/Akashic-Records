# Akashic Records

The shared record archive behind Orbis Arcanorum, World Wonder Web, and World Wicked Web.

Everything written down is one deletion away from a 404. This archive keeps the record of a page after the page is gone: copy first, catalogue second, publish according to rights.

- One record at a time, each with its own source and rights assessment
- Public domain shown whole; copyrighted material as metadata, excerpt, and link
- Nothing deleted — corrections are new revisions, entries are superseded
- Sources checked on a schedule; dead links are the point

Records live in `records/`, validated against `schema/record.schema.json`.

Start at `index.html`, or read `about.html`.

## Rights tiers

| Tier | Meaning |
| --- | --- |
| A | Free to publish — public domain, CC0, government works |
| B | Metadata and snapshot only — copy held dark |
| C | Cleared — permission on file |
| D | Dark — preserved, not shown |
